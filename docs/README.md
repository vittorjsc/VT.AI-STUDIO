# Documentação da VT.AI Studio

- [Guia do usuário](guias/LEIA_ME_USUARIO.md): uso do aplicativo.
- [Beta privado](guias/BETA_PRIVADO.md): instalação, contas, convites e hospedagem de teste.
- [Especificação original](especificacao/00_COMECE_AQUI.md): pacote de construção de setembro de 2026. É registro histórico; o estado atual do produto está no [README principal](../README.md) e no código.
- [Pesquisas](pesquisas/): diagnóstico, benchmark e regras operacionais de qualidade.
- [Validação](validacao/): relatórios históricos e verificador do pacote de referência. Os testes atuais ficam em `tests/` na raiz.

O código de execução permanece em `server.mjs`, `lib/` e `public/`; a base lida pelo aplicativo permanece em `conhecimento/`. `originais/` e `exemplos/` são materiais de referência. `dados-vt-ai/` contém dados privados e não é enviado ao GitHub.
